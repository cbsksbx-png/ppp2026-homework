# 날짜별 메모 캘린더 기획서

## 1. 프로젝트 개요

`tkinter`로 구현한 데스크톱 캘린더 애플리케이션이다. 사용자는 연도와 월을 선택해 달력을 확인하고, 특정 날짜를 눌러 해당 날짜의 메모를 작성·저장한다.

현재 실행 진입점은 `calender_new.py`이며, 날짜별 메모 편집 기능은 `calender_list.py`가 담당한다.

## 2. 목표

- 월간 캘린더를 직관적으로 탐색할 수 있다.
- 날짜마다 독립적인 텍스트 메모를 작성하고 다시 열람할 수 있다.
- 월 이동, 날짜 선택, 저장이 자연스럽게 이어지도록 한다.
- 코드 구조를 단순화해 기능 확장과 유지보수가 쉬운 상태로 만든다.

## 3. 대상 사용자

- 별도 계정이나 서버 없이 개인 일정을 간단히 기록하려는 사용자
- 날짜별 일기, 할 일, 수업·업무 메모를 로컬에 보관하려는 사용자

## 4. 현재 기능

| 구분 | 기능 | 구현 위치 |
| --- | --- | --- |
| 월 선택 | Spinbox 및 좌·우 버튼으로 연도·월 변경 | `calender_new.py` |
| 달력 표시 | 일요일 시작, 6행 × 7열 날짜 버튼 표시 | `calender_new.py` |
| 날짜 선택 | 날짜 버튼을 누르면 해당 날짜의 메모 창 열기 | `calender_new.py` |
| 메모 열기 | `file/<연>-<월>-<일>` 파일 내용을 편집기에 표시 | `calender_list.py` |
| 메모 저장 | 메뉴의 저장 명령으로 텍스트 파일에 저장 | `calender_list.py` |

## 5. 사용자 흐름

```text
앱 실행
  → 현재 연·월의 달력 표시
  → 이전/다음 월 이동 또는 연·월 직접 선택
  → 날짜 선택
  → 날짜별 메모 창 열기
  → 메모 작성 또는 수정
  → 저장
  → 로컬 file 폴더에 날짜별 파일 보관
```

## 6. 화면 및 기능 요구사항

### 6.1 메인 캘린더

- 앱 실행 시 현재 연·월의 날짜를 즉시 표시한다.
- 연도와 월을 직접 선택할 수 있다.
- 이전/다음 월 버튼을 누르면 달력이 즉시 다시 그려진다.
- 1월 이전 또는 12월 이후로 이동할 때 연도도 함께 변경한다.
- 일요일과 토요일은 시각적으로 구분한다.
- 날짜 버튼을 누르면 선택 날짜에 연결된 메모 편집 창을 연다.

### 6.2 날짜별 메모

- 선택 날짜를 창 제목에 표시한다.
- 기존 메모 파일이 있으면 내용을 불러온다.
- 메모가 없어도 빈 편집기를 열어 새 메모를 작성할 수 있다.
- 저장 성공 여부를 사용자에게 알린다.
- 메모 파일명은 날짜순 정렬이 가능한 `YYYY-MM-DD.txt` 형식을 사용한다.

### 6.3 데이터 저장

- 저장 위치는 프로젝트 기준의 `file/` 폴더로 고정한다.
- 실행 위치와 관계없이 동일한 저장 폴더를 사용한다.
- `file/` 폴더가 없으면 저장 시 자동 생성한다.
- 텍스트 인코딩은 UTF-8을 사용한다.

## 7. 개선 우선순위

### 1단계: 사용성 및 기본 동작 안정화 — 완료

1. 앱 시작 시 `render_calendar()`를 호출한다.
2. 이전/다음 월 버튼에서 월 변경 후 달력을 다시 렌더링한다.
3. 연말·연초 이동 시 연도를 함께 조정한다.
4. 연도 Spinbox 범위를 1900년부터 현재 연도+100년으로 확장한다.
5. 날짜 파일명을 `YYYY-MM-DD.txt`로 표준화한다.

### 2단계: 창 및 파일 처리 개선 — 완료

1. 메모 창 생성에 새 `Tk()` 대신 `Toplevel()`을 사용한다.
2. 전역 `text` 변수 대신 각 메모 창이 자기 `Text` 위젯을 관리하도록 변경한다.
3. 파일 경로를 `pathlib.Path`로 구성하고, 저장 폴더를 자동 생성한다.
4. 저장 완료 및 오류를 메시지로 안내한다.

### 3단계: 확장 기능 — 완료

- 오늘 날짜 강조 표시(노란색)
- 메모가 존재하는 날짜에 표시 색상 적용(연녹색)
- 창을 닫을 때 저장하지 않은 변경사항 확인
- 선택 월의 메모 파일명·본문 검색
- `- [ ]`, `- [x]` 형식의 할 일 완료 상태 전환

## 8. 기술 설계 방향

| 영역 | 현재 | 개선 방향 |
| --- | --- | --- |
| 달력 계산 | `datetime`, `calendar.monthrange()` 사용 | 현 방식 유지 |
| 날짜 버튼 콜백 | `functools.partial` 사용 | 현 방식 유지 |
| 창 관리 | 메모 창마다 `Tk()` 및 중첩 `mainloop()` | 메인 `Tk()` 1개 + `Toplevel()` |
| 상태 관리 | 모듈 전역 변수 사용 | 캘린더/메모 클래스로 점진적 분리 |
| 파일 경로 | 상대 경로 문자열 결합 | `Path(__file__).parent / 'file'` |
| 날짜 식별자 | `YYYY-M-D` | `YYYY-MM-DD` |

## 9. 완료 기준

- 실행 직후 현재 달력이 표시된다.
- 이전·다음 월 이동 결과가 즉시 화면에 반영된다.
- 모든 달과 윤년 2월이 올바른 요일 위치 및 일수로 표시된다.
- 날짜별 메모를 저장한 뒤 앱을 다시 실행해도 동일 날짜에서 불러올 수 있다.
- 메모 창을 여러 번 열고 닫아도 메인 캘린더가 정상 동작한다.
- 프로젝트 외부 경로에서 실행해도 메모가 프로젝트의 `file/` 폴더에 저장된다.

## 10. 향후 작업 순서

1. `calender_new.py`의 초기 표시와 월 이동 동작을 수정한다.
2. `calender_list.py`의 창 생명주기 및 파일 경로를 수정한다.
3. 날짜 파일명 규칙을 적용하고 기존 파일의 이전 전략을 정한다.
4. 윤년, 월 시작 요일, 월 경계 이동, 파일 저장·불러오기를 검증한다.
5. 필요 시 클래스로 리팩터링하고 확장 기능을 추가한다.
